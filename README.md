# AEROSTRUCT | Aircraft Structural Analysis & FEM Simulation Lab

Dashboard edukasi analisis struktur balok kantilever (idealisasi sayap) dengan Finite Element Method.
Satu file `index.html`, JavaScript murni, berjalan offline di browser.

**Fitur:** solver FEM Euler–Bernoulli, visualisasi 2D/3D, konvergensi mesh, validasi, analisis frekuensi alami, laporan, glosarium.

> Educational Simulation — Not for Aircraft Certification or Airworthiness Decisions
