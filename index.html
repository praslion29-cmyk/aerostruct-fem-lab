Turunan teori

Fungsi bentuk Hermite & kelengkungan
ξ = x/Le
N1 = 1 − 3ξ² + 2ξ³        N2 = Le(ξ − 2ξ² + ξ³)
N3 = 3ξ² − 2ξ³            N4 = Le(−ξ² + ξ³)
w(x) = N·u_e,   κ = w'' = B·u_e,   B = d²N/dx²
B = (1/Le²)[ −6+12ξ,  Le(−4+6ξ),  6−12ξ,  Le(−2+6ξ) ]
Matriks kekakuan elemen
k_e = ∫₀^Le EI·Bᵀ B dx
Contoh entri k11 = EI/Le³ ∫₀¹ (12ξ − 6)² dξ = EI/Le³ · 12  ✔ (cocok dengan baris pertama matriks)
Satuan: k_ww [N/m], k_wθ [N], k_θθ [N·m/rad]
Beban ekivalen konsisten
f_e = ∫₀^Le Nᵀ q dx = q·[ Le/2, Le²/12, Le/2, −Le²/12 ]ᵀ   (N, N·m, N, N·m)
Perakitan & kondisi batas
K = Σ_e Aᵀ k_e A  (elemen e menempati DOF 2e … 2e+3, node bersama dijumlahkan)
F = Σ_e f_e + beban titik (P pada DOF w node ujung)
Jepit: w₁ = θ₁ = 0 → hapus baris & kolom DOF 1–2 → K_f u_f = F_f
Reaksi: R = K u − F pada DOF terjepit
Eliminasi Gauss + partial pivoting
Untuk kolom k: pilih baris p dengan |a_pk| maksimum (tukar baris k↔p)
m_ik = a_ik / a_kk ;  a_ij ← a_ij − m_ik a_kj ;  b_i ← b_i − m_ik b_k   (i>k)
Substitusi mundur: x_i = ( b_i − Σ_{j>i} a_ij x_j ) / a_ii
Biaya ≈ (2/3)N³ operasi; pivot ≈ 0 → singular
Cholesky (K simetris definit positif)
K = L Lᵀ ;  L_jj = √(a_jj − Σ L_jk²) ;  L_ij = (a_ij − Σ L_ik L_jk)/L_jj
Selesaikan L y = F, lalu Lᵀ x = y. Jika suku di dalam akar ≤ 0 → tidak definit positif → dihentikan.
Recovery momen, tegangan, residual
f_end = k_e u_e − f_e ;  M(kiri) = −f_end[2] ,  M(kanan) = +f_end[4]  (konvensi sagging +)
σ_atas = −M c / I          (tarik +)
Residual relatif = ‖K_f u − F_f‖ / ‖F_f‖ ;  galat rel = |w_FEM − w_analitik| / |w_analitik|

Tentang dashboard


Apa itu AEROSTRUCT?
Laboratorium simulasi edukasi untuk memahami bagaimana matematika, metode numerik, dan Finite Element Method (FEM) dipakai menganalisis struktur pesawat. Modelnya sengaja sederhana: sebuah balok kantilever (dijepit di satu ujung) sebagai idealisasi sayap dari akar sampai ujung. Cocok untuk tugas kuliah, belajar mandiri, dan portofolio.


Alur kerja
Input (geometri, material, beban, mesh) → validasi input → solver FEM menyusun dan menyelesaikan sistem persamaan → hasil defleksi, momen, geser, tegangan → pembandingan dengan rumus analitik → studi konvergensi dan pemeriksaan validasi → resume dan laporan. Setiap angka di layar dihitung ulang dari input saat Anda menekan “Jalankan Analisis”; jika input diubah tanpa menjalankan ulang, status berubah menjadi “hasil lama”.

Apa yang benar-benar dihitung?
  • Dihitung nyata: defleksi, rotasi, momen, geser, tegangan lentur, reaksi tumpuan, residual, frekuensi alami pertama, konvergensi, margin of safety.
  • Hanya visualisasi: skala deformasi, ukuran penampang pada tampilan 3D, warna (warna ilustratif, bukan penentu keselamatan), animasi rampa beban (penskalaan hasil linear, bukan dinamika).
  • Nilai ilustratif: preset material, σ_yield, dan faktor keselamatan bukan spesifikasi bersertifikat.


Teknologi & privasi
Satu file HTML dengan JavaScript murni, grafik memakai canvas/SVG buatan sendiri. Berjalan offline di Chrome/Edge dan tidak mengirim data ke server mana pun. Hasil yang sama selalu muncul untuk input yang sama (deterministik).


Batasan penting
  • Model 1D tidak menggambarkan medan tegangan 3D sayap, torsi, geser, tekuk, kelelahan, beban aerodinamik nyata, atau aeroelastisitas.
  • Asumsi: material linear-elastis, penampang konstan, deformasi kecil, satu jenis tumpuan (jepit).
  • Solver kecil untuk edukasi, bukan paket FEA industri.


Tips presentasi tugas kuliah
Mulai dari Overview, jelaskan model dan asumsi, tunjukkan Perhitungan Detail (n=2) untuk membuktikan Anda paham langkah numeriknya, lanjutkan ke Konvergensi & Validasi, lalu tutup dengan Resume Analisis. Pakai tab Glosarium untuk menjawab pertanyaan istilah.
